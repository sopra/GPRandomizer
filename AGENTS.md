# GPRandomizer Agent Documentation

This document provides context and instructions for AI agents working on the GPRandomizer repository.

## Project Overview
GPRandomizer is a web-based tool for setting up the board game "Gaia Project". It randomizes the initial setup including tiles, map, and other game elements.
The project is a challenge to build a web system using **Vanilla JavaScript** without modern frontend frameworks (like React, Vue, etc.).

## Technology Stack
- **Language**: JavaScript (ES6+), HTML5, CSS3
- **Build Tool**: Gulp (v3.9.1)
- **Linter**: ESLint
- **Package Manager**: npm

## Directory Structure
- **`src/`**: Source code. All development happens here.
    - `js/`: JavaScript logic.
    - `css/`: Stylesheets.
    - `index.html`: Main HTML file.
    - `serviceworker.js`: Service worker for PWA support.
- **`docs/`**: Production build output (GitHub Pages root). **DO NOT EDIT FILES HERE DIRECTLY.**
    - Generated by Gulp from `src/`.

## Build System
The project uses `gulp` to process files from `src/` to `docs/`.
- **`js-minify`**: Concatenates and minifies JS files from `src/js/` to `docs/js/randomizer.js`.
- **`serviceworker-minify`**: Minifies `src/serviceworker.js` to `docs/serviceworker.js` and injects git revision.
- **`html-minify`**: Minifies `src/index.html` to `docs/index.html`.
- **`css-minify`**: Autoprefixes and minifies CSS from `src/css/` to `docs/css/`.
- **`static-copy`**: Copies static assets (images, manifest, etc.) to `docs/`.

## Development Workflow
1.  **Install Dependencies**:
    ```bash
    npm install
    ```
2.  **Development Server**:
    ```bash
    npm start
    ```
    Runs `serve` to preview the app.
3.  **Build for Production**:
    ```bash
    npm run build
    ```
    Runs `gulp` to build assets to `docs/` and commits the changes.

## Key Rules for Agents
- **Always edit `src/` files**, never `docs/` files.
- **Run `npm run build`** after making changes to `src/` to update the production build.
- **Respect the "No Framework" constraint**. Do not introduce React, Vue, or other heavy libraries.
